# RO2RW PC — third-party components

RO2RW PC bundles the following GPLv3 tools; the distributed program is therefore
under **GPLv3** (see `LICENSE`). Source for each bundled tool:

- **mtkclient** — bkerler, GPLv3 — https://github.com/bkerler/mtkclient (dump/flash, default engine)
- **Magisk** — topjohnwu, GPLv3 — https://github.com/topjohnwu/Magisk (official release, boot patching)
- **MTK Flash Tool (fast engine)** — alir325000, GPLv3 — vendored in `third_party/mtkflash/` (see its ATTRIBUTION.md), used with permission

- **lkpatcher** patterns (dm_verity / fastboot / orange / red state) — R0rt1z2, GPLv3 — https://github.com/R0rt1z2/lkpatcher (hex patterns only)

RO2RW concept: LeeGarChat. Also based on: AVB-Disabler, hex-replacer, hovatek's Orange State guide.
