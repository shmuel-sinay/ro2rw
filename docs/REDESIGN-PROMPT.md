# RO2RW PC — קטלוג תכונות + פרומפט לעיצוב מחדש

מסמך זה נכתב כדי לתכנן עיצוב מחדש של הממשק. חלק א' — כל התכונות הקיימות (כדי שלא תאבד אף אחת). חלק ב' — פרומפט מוכן לעיצוב ממשק חדש שבו **כל כלי הוא לשונית עליונה נפרדת עם מסך ייעודי משלו**.

---

## חלק א' — קטלוג כל התכונות הקיימות

### 1. ניהול פרויקטים
- פרויקט = תיקייה לכל מכשיר (תחת תיקיית Projects שבתוך C:\RO2RW).
- יצירת פרויקט חדש (לפי שם המכשיר).
- בחירת פרויקט מרשימה נפתחת.
- פתיחת תיקיית הפרויקט בסייר, פתיחת תיקיית "ערוך".
- בחירת מיקום לתיקיית הפרויקטים.
- סריקת הפרויקט וזיהוי אוטומטי של קבצי רום לפי סוג.
- שמירת מצב: פרויקט אחרון, הגדרות ממשק, מיקום תיקייה.

### 2. קבצים
- הוספת קבצים (בורר קבצים או גרירה).
- זיהוי אוטומטי: super, boot, init_boot, vbmeta, lk ועוד.
- רשימת קבצים עם תיבות סימון. עמודות: שם, סוג, גודל, סוג עריכה, סומן כבר נערך.
- סמן הכל / נקה הכל.
- תפריט ימני על קובץ: ערוך רק אותו · שנה סוג עריכה · תכנון מפורט (super) · עורך HEX · צרוב את הגרסה הערוכה · פתח מיקום · מידע · מחק מהפרויקט.
- כלי "מידע על קובץ": פענוח boot (header, ABI, האם כבר עבר Magisk), מצב AVB ב-vbmeta, רשימת מחיצות ב-super עם סוג מערכת קבצים וגודל.

### 3. כלי עריכה (כל אחד הוא פעולה)
**א. RO2RW (super.img)** — המרת EROFS/ext4 לקריאה-בלבד ל-ext4 לקריאה-וכתיבה עם מקום פנוי:
- מצב אחוזים: אחוז מהמקום הפנוי לכל מחיצה (System / Vendor / Product / Sys_ext / אחרות).
- מצב גודל קבוע: MB קבוע לכל מחיצה.
- פלט sparse (קטן יותר).
- הוספת שורות ext4 ל-fstab של vendor.
- הסרת WiFi (מחיקת wpa_supplicant מ-vendor, למכשיר מסונן) — עם גיבוי.
- תכנון מפורט לפי מחיצה: לכל מחיצה בוחרים אם להמיר וכמה MB להוסיף, עם מד מקום פנוי.
- תמיכה ב-raw / sparse / sparse מפוצל, וגם EROFS וגם ext4.

**ב. Root עם Magisk (boot / init_boot)** — עריכה על המחשב, זהה לאפליקציית Magisk:
- בחירת ABI (אוטומטי / arm64-v8a / armeabi-v7a / x86_64 / x86). זיהוי אוטומטי מקובץ init שב-ramdisk.
- KEEPVERITY, KEEPFORCEENCRYPT, RECOVERYMODE, PATCHVBMETAFLAG.
- בחירת Magisk.apk אחר.
- הורדת גרסת Magisk ספציפית מ-GitHub (למשל 26).
- Magisk מובנה בתוכנה.

**ג. ביטול AVB (vbmeta)**:
- מצב: הכול (verity + verification) / רק verity / רק verification.
- שווה ערך ל-fastboot --disable-verity --disable-verification.

**ד. LK / Orange State (lk.img)**:
- ביטול ההשהיה של 5 שניות.
- מחיקת טקסט האזהרה מהמסך.
- תיקוני dm_verity / fastboot-unlock / red_state (מקור lkpatcher) — מה שגורם למכשיר לדרוש לחיצה כדי לדלוק.
- בחירת גרסת אנדרואיד (אוטומטי / 9 ומטה / 10 ומעלה).

### 4. פעולות מכשיר (MediaTek)
- שאיבת רום מלא מהמכשיר → לתוך הפרויקט בשמות מחיצות + יצירת scatter.
- אפשרות "בלי userdata".
- צריבה חזרה של תיקיית "ערוך" למכשיר.
- צריבת קבצים נבחרים.
- פתיחה ב-SP Flash Tool (צריבה ידנית).
- SP Flash Tool אוטומטי (מצב console, מייצר XML ומריץ flash_tool.exe בלי לחיצות).
- מדריך SP Flash Tool (צריבה ידנית + גיבוי ReadBack).
- התקנת דרייבר USB (UsbDk).
- הורדת SP Flash Tool מהאתר הרשמי.
- התקנת SP Flash Tool לתוך התוכנה (העתקה ל-tools, ניהול מתוך התוכנה).
- **בורר מנוע**: mtkclient (בטוח, ברירת מחדל) · מנוע מהיר USB (UsbDk) · מנוע מהיר דרך COM/serial (VCOM, בלי UsbDk) — מומלץ למכשירים שרק דרייבר ה-VCOM נקלט בהם. אפשר להזין מספר COM ידנית.

### 5. כלים נוספים
- יצירת scatter לתיקיית "ערוך".
- עורך HEX: חיפוש והחלפה, `??` כתו כללי, תבניות מוכנות.
- תכנון מפורט של super.

### 6. מצבי עבודה
- **אשף** — שלב אחרי שלב, כולל כמה MB להוסיף וצריבה בסיום.
- **פרויקט ידני** — שליטה מלאה.
- **כלים בודדים** — עריכת קובץ אחד בלי פרויקט; הפלט נשמר ב"ערוך" ליד הקובץ.
- **צריבה חזרה**.

### 7. ממשק וחוויה
- עברית, ימין-לשמאל.
- הגדלה/הקטנה (Ctrl +/-/0).
- חלון יומן נפרד שניתן להגדיל/למקסם.
- פס התקדמות + שורת מצב עם אחוזים.
- טולטיפים על כל פקד.
- מדריך מפורט (F1), מדריך קצר, אודות.
- ביטול / Esc לכל פעולה; קבצים חלקיים נמחקים.
- עיצוב בהיר ונקי.
- שמירת יומן לקובץ.

## חלק ב' — פרומפט לעיצוב מחדש

> **העתק את הטקסט הבא כפרומפט לעיצוב הממשק.**

עצב מחדש את הממשק של תוכנת Windows בשם **RO2RW PC** — ערכת כלים לעריכת רום של אנדרואיד (MediaTek) על המחשב בלבד, בלי טלפון מחובר לצורך העריכה. התוכנה כתובה ב-C# WinForms (.NET Framework 4.8), עברית מלאה ימין-לשמאל, עיצוב בהיר ונקי.

**העיקרון המרכזי של העיצוב החדש:** היום הכול דחוס בתפריטים נפתחים ("כלים בודדים", כפתור SP שפותח תפריט) ובלשוניות קטנות בצד. **אני רוצה שכל כלי יהיה לשונית עליונה נפרדת עם מסך ייעודי מלא משלו** — לא תפריטים מקוננים. המשתמש רואה שורת לשוניות למעלה, לוחץ על הכלי שהוא רוצה, ומקבל מסך גדול וברור שמוקדש רק לכלי הזה.

### מבנה קבוע (תמיד מוצג, בכל לשונית)
- **כותרת עליונה**: שם התוכנה + בורר הפרויקט הנוכחי (רשימה נפתחת) + כפתור "פרויקט חדש" + כפתור "אשף".
- **פס תחתון קבוע**: שורת מצב + פס התקדמות + כפתור "ביטול".
- **יומן**: ניתן לפתוח בחלון נפרד שאפשר להגדיל (למסכים קטנים). אפשר גם לשומו בתחתית כל מסך.
- כל הטקסט בעברית RTL. תמיכה בהגדלה (Ctrl +/-/0). טולטיפ הסבר על כל פקד.

### שורת הלשוניות העליונה (כל אחת מסך ייעודי)
1. **פרויקט וקבצים** — בורר פרויקט, רשימת קבצים עם תיבות סימון (שם/סוג/גודל/סוג עריכה/נערך), הוספת קבצים + גרירה, סמן הכל/נקה הכל, תפריט ימני לכל קובץ, כלי "מידע על קובץ".
2. **RO2RW (super)** — מסך ייעודי: בחירה בין מצב אחוזים (לכל מחיצה) למצב גודל קבוע, sparse, fstab, הסרת WiFi, וכפתור "תכנון מפורט לפי מחיצה" שפותח טבלה עם מד מקום פנוי. כפתור "בצע" גדול בתחתית המסך.
3. **Root (Magisk)** — מסך ייעודי: בחירת ABI, KEEPVERITY/KEEPFORCEENCRYPT/RECOVERYMODE/PATCHVBMETAFLAG, בחירת/הורדת גרסת Magisk, הצגת הגרסה שתשמש. כפתור "בצע".
4. **AVB (vbmeta)** — מסך ייעודי: בחירת מה לכבות (הכול / verity / verification), הסבר. כפתור "בצע".
5. **LK / Orange State** — מסך ייעודי: ביטול השהיה, מחיקת טקסט אזהרה, תיקוני dm_verity/fastboot/red_state, בחירת גרסת אנדרואיד. כפתור "בצע".
6. **שאיבה** — מסך ייעודי: בחירת מנוע (mtkclient / מהיר USB / מהיר serial-COM), אפשרות "בלי userdata", הוראות חיבור המכשיר, כפתור "שאב רום מהמכשיר", התקנת דרייבר.
7. **צריבה** — מסך ייעודי: בחירת מה לצרוב (תיקיית "ערוך" / קבצים נבחרים), בחירת מנוע, רשימת מחיצות עם סימון, אזהרת גיבוי, כפתור "צרוב".
8. **SP Flash Tool** — מסך ייעודי (במקום כפתור שפותח תפריט מבלבל): שלושה מצבים ברורים כבלוקים נפרדים — "אוטומטי (מומלץ)", "פתח ידנית", "מדריך + גיבוי ReadBack" — וכן התקנת SP לתוך התוכנה והורדה מהאתר הרשמי.
9. **HEX וכלים** — עורך HEX עם חיפוש/החלפה ו-`??`, יצירת scatter, תכנון super, מידע על קובץ.
10. **עזרה** — מדריך מפורט, מדריך קצר, אודות.

### עקרונות עיצוב
- כל מסך כלי: כותרת קצרה + הסבר שורה אחת למעלה, הפקדים באמצע, וכפתור פעולה ראשי גדול וברור בתחתית המסך (לא מפוזר). צבע ירוק לפעולת עריכה, אדום לצריבה, כחול לפעולות מכשיר.
- אל תסתיר פונקציות בתפריטים נפתחים מקוננים. כל פעולה עיקרית = כפתור גלוי במסך הרלוונטי.
- הממשק חייב לעבוד יפה גם במסך קטן (14 אינץ') — בלי טקסט חתוך, בלי גלילה אופקית. חלון שמתחיל ממוקסם, פקדים שמסתדרים לרוחב, גופן קריא.
- שמור על כל התכונות שבחלק א' — אף אחת לא נעלמת, רק מסודרת אחרת.
- RTL מלא, עברית, עיצוב בהיר, שטוח ונקי (כותרת כחולה, כפתורים שטוחים, רקע בהיר).

סוף הפרומפט.
