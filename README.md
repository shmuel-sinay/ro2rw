# RO2RW PC

קובץ EXE אחד לווינדוס לעריכת רום של אנדרואיד: RO2RW (‏super לקריאה וכתיבה), Root עם Magisk, ביטול AVB והסרת Orange State.

הכול נעשה **על המחשב בלבד**: בלי טלפון, בלי ADB ובלי כלים חיצוניים. בסוף מקבלים super חדש לצריבה.

## התקנה

- **RO2RW-PC-Setup.exe** (מומלץ): מתקין ל-`C:\RO2RW` עם קיצורי דרך בתפריט התחל ובשולחן העבודה. הפרויקטים, הכלים וההגדרות נשמרים **בתוך תיקיית התוכנה**, והעדכון הבא מתקין על הקיים בלי לאבד פרויקטים.
- **RO2RW-PC.exe** (נייד): בלי התקנה, מריצים ישירות (שמים בתיקייה משלו).

## הורדה

בדף **Releases** → `latest` → מורידים את **`RO2RW-PC.exe`**.
הקובץ נבנה אוטומטית ב-GitHub Actions בכל עדכון, אחרי שכל הבדיקות עוברות.

דרישות: Windows 10 או 11 (‎.NET Framework 4.8 מובנה בהם).

## שלוש דרכי עבודה

- **🧙 אשף**: עובר איתך על הכול שלב אחרי שלב: פרויקט, מקור (שאיבה מהמכשיר או קבצים), אילו עריכות, כמה MB להוסיף לכל מחיצה (system, vendor, product, system_ext...), הגדרות Magisk ו-LK, וצריבה חזרה בסיום. בסוף מוצג סיכום, וכל השלבים רצים ברצף.
- **ידני (פרויקט)**: כמו שמתואר בהמשך, עם שליטה מלאה. קליק ימני על קובץ פותח אפשרויות: עריכה של הקובץ הזה בלבד, שינוי סוג העריכה, צריבה של הגרסה הערוכה שלו, מידע על הקובץ ומחיקה.
- **כלים בודדים** (תפריט "כלים בודדים"): כל כלי לבד, על קובץ אחד, בלי פרויקט. Root לקובץ boot, RO2RW לקובץ super, ביטול AVB, הסרת Orange State, ומידע על קובץ. הפלט נשמר בתיקייה `ערוך` ליד הקובץ.

## אפשרויות מפורטות

| כלי | אפשרויות |
|---|---|
| RO2RW | MAX (אחוזים), FIXED (MB קבוע), **הסרת WiFi** למכשיר מסונן (מחיקת wpa_supplicant מ-vendor, בלי לגעת ב-XML, עם גיבוי), **תכנון מפורט לפי מחיצה**: לכל מחיצה בוחרים אם להמיר וכמה MB להוסיף, עם מד מקום פנוי חי. התכנון נשמר ליד ה-super. sparse, ‏fstab של vendor |
| Magisk | ABI (אוטומטי או ידני), KEEPVERITY, KEEPFORCEENCRYPT, RECOVERYMODE, PATCHVBMETAFLAG, בחירת APK אחר |
| vbmeta | לכבות הכול, רק verity, או רק verification |
| LK | ביטול ההשהיה, מחיקת הטקסט, גרסת אנדרואיד, ותיקון dm_verity / fastboot-unlock / red_state (מקור: lkpatcher) שמסיר את הצורך בלחיצה כדי לדלוק |
| עורך HEX | חיפוש והחלפה עם `??` כתו כללי, ותבניות מוכנות |

## נגישות ונוחות

- **עצירה באמצע של כל פעולה**: כפתור "ביטול" או מקש **Esc**. קבצים חלקיים נמחקים.
- הסבר (tooltip) על כל אפשרות, ומדריך מפורט בעזרה (**F1**).
- קיצורי מקשים: Ctrl+W אשף, Ctrl+N פרויקט חדש, Ctrl+O הוספת קבצים, Ctrl+E עריכה, Ctrl+F צריבה, F5 רענון.
- הגדלה והקטנה של כל הממשק: **Ctrl +** ו-**Ctrl -** (נשמר בין הפעלות).
- אפשר לבחור מיקום אחר לתיקיית הפרויקטים.

## מנוע צריבה / שאיבה (mtkclient או המנוע המהיר)

בתפריט **מכשיר ← מנוע צריבה / שאיבה** אפשר לבחור:
- **mtkclient** (ברירת מחדל, בטוח): נבדק על אלפי מכשירים.
- **המנוע המהיר של אליר** (ניסיוני): נבנה מ-"MTK Flash Tool for macOS" מאת alir325000 (בשימוש באישורו), עם העברות USB גדולות (~כמה מגה-בייט לשנייה). נבדק על מעט מכשירים — ⚠️ צריבה יכולה להשבית מכשיר, השתמש בו רק אם אתה מקבל את הסיכון. הבחירה נשמרת בין הפעלות, וחלה גם על השאיבה וגם על הצריבה.

## צריבה חזרה למכשיר

כפתור **"⬆ צרוב חזרה"** (או תפריט "מכשיר"): צורב את תיקיית `ערוך` חזרה למכשיר עם mtkclient המובנה.
- שמות המחיצות נבדקים מול `gpt.bin` (למשל `boot.img` נצרב ל-`boot_a`). אפשר לשנות כל שם ידנית.
- גודל כל קובץ נבדק מול גודל המחיצה שלו.
- קובץ super בפורמט sparse מומר אוטומטית לקובץ רגיל לפני הצריבה.
- מחיצות רגישות (preloader, nvram, proinfo, seccfg...) חסומות לצריבה.
- לפני הצריבה מוצג חלון אישור עם הרשימה המלאה. אחרי הצריבה יש אפשרות לאתחל את המכשיר.

ההגדרות האחרונות והפרויקט האחרון נשמרים בין הפעלות, בקובץ `RO2RW-PC.ini`.

## שימוש: פרויקט לכל מכשיר

1. **פרויקט חדש**: נותנים שם, בדרך כלל שם המכשיר. נוצרת תיקייה `Projects\<שם>` ליד התוכנה.
2. **הוספת קבצים**: אחת משתי דרכים:
   - **שאיבה מהמכשיר** (MediaTek): כפתור "שאב רום מהמכשיר". mtkclient מובנה בתוכנה, שואב את כל המחיצות לתוך הפרויקט בשמות המחיצות (`boot_a.img`, `lk_a.img`...), ויוצר גם `gpt.bin`, קובץ scatter ויומן. בפעם הראשונה לוחצים "דרייבר USB" כדי להתקין את UsbDk.
   - **קבצים קיימים**: כפתור "הוסף קבצים" או גרירה לחלון.

   התוכנה מזהה כל קובץ לבד:

| קובץ | עריכה |
|---|---|
| `super.img` (raw, sparse או מפוצל) | **RO2RW**: ממיר את המחיצות ל-ext4 לקריאה וכתיבה, עם מקום פנוי (MAX או FIXED) |
| `boot.img` / `init_boot.img` | **Root עם Magisk** (מובנה): עריכה על המחשב, זהה לאפליקציית Magisk. ה-ABI מזוהה מקובץ init שב-ramdisk |
| `vbmeta*.img` | **ביטול AVB**: verity ו-verification כבויים (הלוגיקה של AVB-Disabler) |
| `lk*.img` / `lk*.bin` | **הסרת Orange State**: ביטול ההשהיה של 5 שניות ומחיקת טקסט האזהרה. גרסת האנדרואיד מזוהה אוטומטית |

   כברירת מחדל מסומנים רק קבצי חריץ A, רק vbmeta הראשי, ו-init_boot במקום boot כשקיים.

3. **בצע עריכה**: הקבצים הערוכים נשמרים בתיקייה **`ערוך`** בתוך הפרויקט, עם אותם שמות. המקור לא משתנה. נוצרים גם `HOW_TO_FLASH.txt` וקובץ **scatter ל-SP Flash Tool**, שבו מסומנות לצריבה רק המחיצות שנערכו. ה-scatter נבנה מה-scatter של הקושחה אם הוא בפרויקט, ואם לא, מ-`gpt.bin` שנוצר בשאיבה.

## צריבה

```bash
fastboot flash super super.img
```

```bash
fastboot flash vbmeta vbmeta.img
```

(מתוך התיקייה `ערוך`. אפשר לצרוב גם ב-SP Flash Tool או ב-mtkclient.)

> ⚠️ גבו את המכשיר לפני הצריבה. האחריות על המשתמש. חובה לכבות את האימות (vbmeta).

## מה נתמך

| | |
|---|---|
| קלט super | raw, sparse, sparse מפוצל, מטא-דאטה LP בגרסאות 10.0–10.2 |
| EROFS | ללא דחיסה, inline, chunked, LZ4/LZ4HC, DEFLATE, ztailpacking, fragments, dedupe, big pcluster |
| ext4 | extents, block map, inline_data, 64bit, metadata_csum, shared_blocks |
| נשמר | הרשאות, בעלות, SELinux ‏(xattrs), capabilities, קישורים קשיחים וסמליים, התקנים |
| פלט | ext4 חדש (4K, extents, ללא journal), super חדש עם מטא-דאטה מעודכנת בכל החריצים |
| לא נתמך עדיין | EROFS עם LZMA או ZSTD |

ב-vendor נוספות אוטומטית שורות ext4 ל-`etc/fstab.*` לצד שורות ה-erofs.

## מבנה

- `src/Core`: הליבה (sparse, LP metadata, EROFS/ext4, כותב ext4, boot image, cpio, Magisk, LK, vbmeta, פרויקטים)
- `src/App`: ממשק גרפי (WinForms, עברית)
- `tests`: בדיקות אוטומטיות שמשוות מול `mkfs.erofs`, `mke2fs`, `e2fsck` ו-`debugfs`
- `legacy-adb`: הגרסה הקודמת, שהפעילה את סקריפט RO2RW המקורי בטלפון דרך ADB

רעיון ההגדרות (MAX/FIXED, S/V/P/SE/OT) מבוסס על RO2RW מאת LeeGarChat.

מבוסס על: RO2RW מאת LeeGarChat · ‏Magisk מאת topjohnwu (‏boot_patch.sh ו-magiskboot) · ‏AVB-Disabler · ‏hex-replacer · המדריך של hovatek ל-Orange State.
