# RO2RW Manager

תוכנה לווינדוס להפעלת הסקריפט **RO2RW 3.7.3.0s** (מאת LeeGarChat) מהמחשב, דרך כבל USB ו-ADB.

RO2RW רץ על הטלפון עצמו, ב-TWRP או דרך Magisk. התוכנה עושה את כל השאר:

- מורידה **אוטומטית** את חבילת RO2RW מ-SourceForge, בלי לבחור קבצים
- מורידה את ADB (platform-tools של Google) בלחיצה אחת
- עורכת את `config.txt` בממשק נוח (אחוזי הגדלה, FORCE_START, גיבוי ועוד) ובונה ZIP מותאם
- מעבירה את ה-ZIP לטלפון ומריצה אותו, ומציגה **יומן חי** במחשב
- במצב Magisk אפשר לענות לשאלות הסקריפט מתיבת קלט
- מושכת את יומני `NEO.LOGS` מהטלפון למחשב
- כפתורי אתחול ל-Recovery, למערכת ול-Fastboot

## הפעלה

1. מורידים את התיקייה (Code → Download ZIP) ומחלצים.
2. לוחצים פעמיים על **`Start-RO2RW.cmd`**.

דרישות: Windows 10/11 (PowerShell 5.1 מובנה) וחיבור לאינטרנט בהפעלה הראשונה.

## שיטות הפעלה

| שיטה | מצב הטלפון | הערות |
|---|---|---|
| TWRP - יומן חי במחשב (מומלץ) | TWRP | בחירה בלחצני העוצמה: (+) עובר לאפשרות הבאה, (-) בוחר |
| TWRP - התקנה רגילה | TWRP | הפלט מוצג רק בטלפון |
| ADB Sideload | TWRP | |
| Magisk - התקנת כלי RO2RW | מערכת + root | נדרש אתחול לאחר מכן |
| Magisk - הרצת RO2RW | מערכת + root | עונים לשאלות מתיבת הקלט שבתוכנה |

> ⚠️ הסקריפט משנה מחיצות מערכת. גבו את המכשיר לפני ההפעלה. האחריות על המשתמש.
